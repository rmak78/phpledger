# Regional suggestions

`country-defaults-cldr48.json` contains 258 named territory entries derived from Unicode CLDR 48.0.0. The registry records the exact source URLs and SHA-256 hashes; `UNICODE-LICENSE.txt` preserves the upstream Unicode License v3 notice.

English names come from CLDR territory names. Regional locale suggestions come from `likelySubtags` (`und-XX`), with `en-Latn-XX` only when CLDR has no territory-specific default. These are editable format suggestions, not a determination of a person's language, residency, tax jurisdiction, or UI translation coverage.

Currency lists include only tender entries whose CLDR date intervals include **2026-09-14**. They are a dated snapshot. Multiple current tender currencies remain explicit; PHP Ledger does not silently choose one. The current application supports USD, EUR, GBP, PKR, INR, MYR, BDT, LKR, NPR and SGD as base currencies. Other currencies remain visible as regional information and require a manual supported choice. This does not implement foreign exchange.

The requested additions reuse the existing CLDR mappings: Malaysia (`MY` → `MYR`, `ms-Latn-MY`), Bangladesh (`BD` → `BDT`, `bn-Beng-BD`), Sri Lanka (`LK` → `LKR`, `si-Sinh-LK`), Nepal (`NP` → `NPR`, `ne-Deva-NP`) and Singapore (`SG` → `SGD`, `en-Latn-SG`). `pl_base_currency_options()` supplies the shared choices for demo/normal onboarding and their server validation. Existing sessions reapply this local support list to the cached country code without another network lookup. A new sample uses its chosen currency for source documents, POS and reports; returning to an existing sample does not change its currency or convert its values. These are currency choices, not implemented regional accounting/tax frameworks or localized industry prices.

The user selected one free public country lookup per browser session. The application sends only a validated public IP to `https://api.country.is/{ip}`, with a two-second HTTP timeout and no optional city, coordinates, or other fields. It caches success, unavailable results, and local-network skips in `regional_suggestion`; login/logout session rotation preserves that cache. IP addresses and raw responses are not retained in it. A country suggestion does not override confirmed business settings.

`REMOTE_ADDR` is authoritative unless it exactly matches an entry in `PL_TRUSTED_PROXY_IPS`. Only then may a validated `X-Forwarded-For` chain identify the nearest untrusted hop. A missing or malformed chain, private/reserved address, unknown country, API error, or unavailable mapping leaves manual choices available. Deployment must configure the proxy to overwrite forwarded client headers.

Sources reviewed 2026-09-14: [Country API](https://country.is/), [CLDR currency data](https://raw.githubusercontent.com/unicode-org/cldr-json/48.0.0/cldr-json/cldr-core/supplemental/currencyData.json), [likely subtags](https://raw.githubusercontent.com/unicode-org/cldr-json/48.0.0/cldr-json/cldr-core/supplemental/likelySubtags.json), and [English territory names](https://raw.githubusercontent.com/unicode-org/cldr-json/48.0.0/cldr-json/cldr-localenames-full/main/en/territories.json). The earlier offline-MMDB proposal was superseded before any dependency or updater was added.
