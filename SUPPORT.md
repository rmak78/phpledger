# Support

Maintenance of PHP Ledger has stopped for lack of funds, so no further updates are planned. To help restart it, see https://phpledger.com/funding/.

While maintenance is stopped there is no support: questions, bug reports and feature requests are not answered, and no fixes are planned.

- **The latest release:** the source code and the installable package are on the [1.4.7 release page](https://github.com/phpledger/phpledger/releases/tag/v1.4.7).
- **Installing and upgrading:** `README.txt` inside the release ZIP, [INSTALL.md](resources/release/INSTALL.md) and [UPGRADE.md](resources/release/UPGRADE.md).
- **Security problems:** report them privately as described in [SECURITY.md](SECURITY.md).

If you use PHP Ledger, keep your own verified backups, keep your server, PHP and database patched, and have your accountant review your books.

The public demo at https://phpledger.com/demo/ is for evaluation only. It is reset regularly, so anything you enter disappears; do not enter real records, credentials or documents.
