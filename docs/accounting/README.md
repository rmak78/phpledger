# Accounting and report implementation references

The user requires the **accounting system itself** to follow the applicable accounting guidelines, informed by **ICMA Pakistan, ICAP and ACCA**. Country priority is **Pakistan, then UK, then UAE**. Each profile must establish legal/entity eligibility, locally applicable framework and effective edition, recognition and measurement policies, accounting workflows, statements and disclosures. A currency or IP-country suggestion must not select those rules automatically.

The current application is a tested accounting preview, not a complete supported country package. The user's report/POS feedback put publication on hold while this research informs the redesign. The preceding sprint implementation and validation records remain preserved.

- [Pakistan reporting research](PAKISTAN_REPORTING_RESEARCH.md): SECP classification, ICAP/ICMAP/ACCA guidance, actual illustrative formats, edition checks and system requirements.
- [UK and UAE reporting research](UK_UAE_REPORTING_RESEARCH.md): framework choices, authoritative format references, effective dates and access limits.
- [Reporting gap analysis](REPORTING_GAP_ANALYSIS.md): current schema/service evidence, mapping/version/completeness needs, and implementation sequence.
- [Original two-year retail example](examples/retail-statements.md): reconciled synthetic statements for design and later acceptance fixtures. It is not installed sample data or a tax calculation.
- [POS research](../design/POS_RESEARCH.md): observed current-screen problems and public product references, including the requested CodeCanyon comparison as it is completed.
- [Typography study](../design/typography-review/README.md): designer reference and font roles, with Inter retained for financial figures.

Before a profile is described as supported, maintain a traceable requirement register: official source/paragraph, effective date, reviewer interpretation/policy, implementation, reconciled fixture and measured acceptance result. Verify current laws/notifications and applicable rights to use reference material. Accounting review and user task testing remain open; no professional-body endorsement is implied.
