# Accounting starter screenshot assets

Six actual application captures accompany the 0.4.0-preview media kit. All records are fictional. They are original PNG copies, with no generated or altered interface content. These are local acceptance captures, not evidence of a live deployment or customer adoption.

The four playground images use a local instance of the restricted public-demo runtime. The printable invoice and completed bank reconciliation use a different sample self-hosted acceptance company. Their figures are independent examples and must not be combined into one company's accounts.
