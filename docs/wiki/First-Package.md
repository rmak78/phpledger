# The first stable package

**1.0.0**, published 18 September 2026, is PHP Ledger's first stable release. [Download 1.0.0](https://github.com/phpledger/phpledger/releases/tag/v1.0.0) and its [matching media kit](https://github.com/phpledger/phpledger/releases/download/v1.0.0/phpledger-1.0.0-media-kit.zip). Compare the ZIP against its SHA-256 checksum; 1.0.0 ships without signed update metadata because the publisher signing key had not been generated at publication.

[[Release 1.0.0|Release-1.0.0]] is the current, detailed record of what shipped, its verification evidence and what it does not include. This page is a short pointer; earlier per-release pages (for example [[0.6.0-preview release|Release-0.6.0-preview]]) remain historical.

Automated test suites, fault-injection update/recovery tests, exact-artifact install/upgrade/recovery checks and developer-operated browser checks back 1.0.0. Independent accounting review, independent security review, supervised pilots with a real month-end close, unfamiliar-operator installation observation and restricted shared-host recovery certification have **not** happened; these continue as post-release commitments.

Modern source is under `www/phpledger`, with historical code retained only in Git history. New project-owned code and documentation use [AGPL-3.0-or-later](https://github.com/phpledger/phpledger/blob/master/LICENSE); [dependency, asset and historical terms](https://github.com/phpledger/phpledger/blob/master/LICENSE-SCOPE.md) remain separate.

See [[Getting started|Getting-Started]] for installation and upgrade instructions, [[Accounting and reports|Accounting-and-Reports]] for the accounting scope, and [[Module roadmap|Module-Roadmap]] for what comes after 1.0.0.
