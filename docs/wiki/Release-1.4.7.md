# PHP Ledger 1.4.7: maintenance has stopped

Prepared from the versioned release notes. Publication status, exact artifacts and completed verification gates are established by the [published release](https://github.com/phpledger/phpledger/releases) and its receipt under `docs/repository/`; this page describes what the release contains.

Maintenance of PHP Ledger has stopped for lack of funds, so no further updates are planned. To help restart it, see https://phpledger.com/funding/.

- **Maintenance notice:** the Updates and privacy screen, which shows the installed version and checks for releases, says so in plain text, and so do the package's `README.txt` and the INSTALL and UPGRADE guides.

No migration. Upgrade from 1.4.6 by replacing the files as usual. No media kit, per the patch-release policy. See [[Getting started|Getting-Started]].
