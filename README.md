# PHP Ledger

PHP Ledger is open-source, self-hosted double-entry accounting with a cash point of sale. Maintenance has stopped for lack of funds, so no further updates are planned. To help restart it, see https://phpledger.com/funding/.

The source code and the installable package of PHP Ledger 1.4.7 are on the release page:
https://github.com/phpledger/phpledger/releases/tag/v1.4.7
