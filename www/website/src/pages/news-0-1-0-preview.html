PHP Ledger 0.1.0-preview is available

14 September 2026 · Release announcement

The first evaluation package brings the modern PHP Ledger foundation into a downloadable installation for PHP 8.5 and MySQL 8.4.

What you can evaluate

Create a sample company, save and post receipts or expenses, inspect a balanced journal, follow a linked reversal and open the trial balance, profit and loss and balance sheet. The cash point of sale includes a small illustrative catalog, tender, change and a printable receipt.

What the package includes

The ZIP includes production dependencies, five versioned migrations, preflight and initial-user commands, installation and upgrade guides, and licence notices. New project-owned code is MIT licensed. Historical application code is excluded and retains its separate terms.

Where the preview ends

This is an evaluation release. Receivables, payables, stock and cost of sales, tax, historical imports, opening cutover, reconciliation, offline use and foreign-currency posting are outside this package. Qualified regional accounting and observed usability review remain open.

Use sample data, verify the package checksum and follow its INSTALL.md. Existing-business opening positions need reconciliation before a later supported accounting release can take over the books.
