PHP Ledger 0.1.6-preview

15 September 2026 · Maintenance release

PHP 8.2 is now the minimum, with PHP 8.3 recommended for deployment. PHP Ledger remains a country-neutral accounting core, with regional tax integrations delivered as connectors.

Hosting compatibility

The package includes dependencies compatible with PHP 8.2. Use the same supported PHP configuration for web requests and installation commands. MySQL 8.4, required PHP extensions, HTTPS and the public document root remain part of the installation profile. PHP availability in a hosting panel alone does not verify the whole hosting plan.

Open-source core and contributor agreement

This release uses AGPL-3.0-or-later for project-owned code. The core remains open source, and a separate commercial licence is available. Self-hosting remains free, with no licence keys or licensing-server calls. Published 0.1.0 through 0.1.5 previews retain their original MIT grants. New contributions use the published CLA; third-party notices remain intact.

A country-neutral product

PHP Ledger serves small businesses, owners, bookkeepers, accountants and multi-company operators across countries. Pakistan is one intended direction. FBR digital invoicing is one planned connector, with its own supported scope and review gates.

Upgrade scope

This maintenance release preserves the existing eleven migrations and accounting data model. It retains the current accounting and sample POS workflows. API/MCP access and richer multi-year samples remain separate development work with open release gates.
