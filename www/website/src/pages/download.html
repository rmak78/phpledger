Install from the included guide

  1. Unpack privately

    Read INSTALL.md. Keep configuration, dependencies and installation tools outside the web document root.

  2. Configure the host

    Use a dedicated database account and private config. Set production mode, HTTPS and routing as described in the package.

  3. Check and initialize

    Run preflight, migration and preflight again, proceeding only when each command succeeds. Keep all seventeen migration files supplied with this version, including both distinct 006 files and foundations migrations 013–016. Never rename or change an applied migration.

  4. Verify with sample books

    Create the initial sign-in user using secure stdin. Test a sample receipt, account statement, general-journal draft, posting, report and linked reversal.

For an existing database, read UPGRADE.md first and rehearse a private backup restore. The historical 2015 application and its SQL dumps are excluded from the new installation path.

The package includes reviewed opening trial-balance/CSV cutover and unpaid-document reconciliation. Detailed historical journals, XLSX and customer/vendor settlement workflows remain future work. Evaluate with synthetic records and synthetic examples only.

Frequently asked questions

What hosting does this package need?

Use PHP 8.2 or newer (8.3 recommended) for both web and command-line requests, MySQL 8.4 with InnoDB, HTTPS and private writable PHP session storage. PHP needs BCMath, PDO, PDO MySQL, mbstring, cURL, OpenSSL and fileinfo. Installation is done in the browser at /install; no terminal access is required for setup, though CLI installation remains available. Serve only www/phpledger/public; MariaDB is not validated for this package.

Do I need Composer to install the download?

No. The ZIP includes production dependencies and its installation guide. Keep vendor files, configuration and installation tools outside the web document root.

How do I check that the ZIP is intact?

Download the ZIP and its SHA-256 file from the same GitHub release. Calculate the ZIP checksum using the command above and compare it with the published checksum before unpacking.

Does downloading the ZIP upgrade my existing installation?

No. Read the included UPGRADE.md, which covers recognized prior modern installations. Back up the database and application, rehearse restoration, then follow its maintenance, preflight and migration steps, or use the signed in-browser updater at /maintenance.php. Historical installations and customized schemas need separate review.

Can I bring an existing business into 1.0.0?

1.0.0 supports opening trial-balance/CSV review, explicit cutover confirmation and an unpaid-document register reconciled to control accounts. Detailed historical imports and operator AR/AP settlement workflows are not included. Use synthetic data for evaluation, and obtain independent accounting review before a real business cutover.
