The path from a first stable release to independently reviewed books

The published package has a bounded accounting starter spanning customer and supplier documents, payments and optional stock workflows, plus browser installation and signed updates. Independent review, pilots and the release-candidate acceptance period continue after publication as disclosed post-release commitments.

In short

  • PHP Ledger {{site.release.version}} is the first stable release, with core AR/AP, optional Purchasing and Inventory, manual tax, reports, scoped read connections, browser installation and signed automatic updates.
  • Invoices, bills, partial payments, linked credits, ageing and reconciliation now use the shared party, open-item and correction foundations.
  • Advanced inventory, statutory tax adapters, reviewed statement packages, independent accounting/security review and supervised pilots each need separate delivery and acceptance evidence, disclosed as open post-release commitments rather than completed gates.

This roadmap describes development scope, not a delivery-date or regulatory-compliance promise.

Frequently asked questions

Is there a stable release?

Yes. PHP Ledger 1.0.0, published 18 September 2026, is the first stable release, consolidating browser installation and signed automatic updates with the existing accounting core. Independent accounting review, independent security review and supervised pilots have not yet happened; they continue as post-release commitments, disclosed alongside the release rather than presented as satisfied.

Does choosing a country or currency activate local accounting rules?

No. Each book uses one base currency. Country and currency choices do not activate tax calculations, statutory reporting, foreign-currency posting or additional accounting books. The core is country-neutral. Pakistan FBR is one planned connector; each regional accounting or tax integration needs separate research, implementation and review.

How can I help shape the next release?

Share a fictional workflow example, installation report or reproducible issue through the project repository. Accountants, business owners and contributors can also use the enquiry form on the pricing page to prepare a message about review or pilot participation.

Which parts are ready to evaluate?

Use the release boundary to choose a test task; a schema foundation does not mean the operator workflow is available.
