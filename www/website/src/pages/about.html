Accounting you can inspect and host yourself

PHP Ledger is an open-source accounting project for small businesses, maintained by Rana Mansoor Akbar Khan with support from the BixiSoft community.

A useful accounting core comes first

The current {{site.release.version}} preview records receipts, expenses and general journals through one double-entry posting service. Reports connect figures to their account movements and source records. Optional business modules build on that core.

The application uses PHP 8.5, MySQL 8.4 and MeekroDB in BixiSoft's modular PHP structure. New project-owned code and documentation are MIT licensed. Dependencies, fonts, photographs and historical source keep their own terms.

Built in the open

Contributors help improve accessibility, accounting checks, installation guidance and everyday workflows. Browse the source repository, Wiki and roadmap to see implemented work and remaining gates.

What preview means

Use synthetic records while evaluating the software. Qualified accounting review, jurisdiction-specific reporting, independent security review and observed business usability remain open gates. A balanced report alone does not establish compliance.
