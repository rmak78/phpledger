Accessible sample checkout in 0.1.5-preview

15 September 2026

Every fallback quantity field now identifies its product, and product cards give the fields enough room when JavaScript is disabled.

PHP Ledger guidance: use this page with the matching release notes and evaluate the workflow using synthetic records.

A contribution and a follow-up

Nagulanvelu contributed the accessible quantity names in PR #65. Browser review then identified clipped fallback controls; a maintainer layout correction makes them visible at desktop, tablet and mobile sizes.

Checked through the full checkout

Synthetic checks cover cart review, explicit cash confirmation, CSRF and forged-total rejection, retained invalid inputs, exact change and linked journal/source records. Duplicate checkout returns the original receipt. The exact package passed a fresh installation and an upgrade from 0.1.4-preview with migration receipts and balances preserved.

Clearer project information

Read the new About, Privacy and demo-use terms pages, plus six product FAQs. The demo uses temporary fictional books; cash checkout does not collect payment.

This release preserves the accounting behavior of 0.1.4-preview. Scoped API/MCP reads and four multi-year demo companies are later milestones with separate access, reconciliation and client-compatibility gates. Technical checks do not establish professional accounting approval or observed participant success.
