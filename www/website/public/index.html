A few things to know.

Can I use this for live bookkeeping today?

PHP Ledger is in development. The public demo is a temporary sample environment. A stable release and supported pilot use need their own accounting, security, installation and usability checks.

How can I install the new PHP Ledger?

The 0.1.0-preview package is available for evaluation with synthetic data. It includes production dependencies and installation instructions for PHP 8.5 and MySQL 8.4. Follow the Getting Started guide for requirements and known limits. Use the public demo to evaluate the current work with temporary sample data.

Can I import my old records?

Historical imports are planned for the next phase. They will preview mappings, errors and totals before confirmation, with opening balances and unpaid documents reconciled at a cutover date.

Will it work for my country or currency?

The first core is country-neutral. A currency display is not tax or foreign-exchange support. Additional languages, reviewed country templates and multicurrency accounting are future work.

What happens to the demo data?

The demo uses synthetic records and resets every hour. Changes are temporary. Do not enter real customer details, confidential financial records or passwords you use elsewhere.
