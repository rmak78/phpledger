The path from a working preview to supported books

The published package has a bounded accounting and cash-sale journey. Each next step needs reconciled examples, access checks and review before it becomes a supported capability.

This roadmap describes development scope, not a delivery-date or regulatory-compliance promise.

Development sequence

  1. Available

    0.1.2-preview

    Accounts, journals and linked reversals; account ledgers with visible running balances; reviewed opening trial-balance/CSV cutover; period administration; bank CSV reconciliation; management reports and CSV exports; bundled core/POS modules with owner enablement and retained history.

    Download the evaluation package

    Development preview
  2. Next implementation

    API and MCP read access

    Read authorized companies, capabilities, accounts, journal sources, trial balances and account statements through the same scoped accounting services. Validate revocation, pagination, exact amounts and real-client parity.

    Next milestone
  3. Following

    Controlled commands

    Draft, validate, post and reverse with explicit permissions, configured review policy, durable retry protection and traceable command receipts.

    Planned
  4. Optional AR/AP

    Customer and vendor subledgers

    Invoices, bills, receipts/payments, allocations, credit notes, running party balances and aging that reconcile to ledger control accounts.

    Unfinished
  5. Accounting acceptance

    Reviewed reporting

    Versioned account mappings, true comparatives, completeness checks, reproducible report snapshots and qualified review for the chosen entity and framework. The current reports are management previews, not issued statutory statements.

    Unfinished
  6. Parallel priority

    SEO discovery and launch preparation

    Maintain crawlable public documentation and release news, verify search ownership and indexing, and prepare evidence-based campaign material. Account setup and campaign execution are tracked separately from product capability.

    High priority

Help test a real task

Useful contributions include synthetic worked accounting examples, installation results, reproducible bugs and feedback from owners and bookkeepers. Independent security, accounting and observed usability review remain open gates.

Frequently asked questions

When will a stable release be available?

There is no committed stable-release date. A supported release needs reconciled accounting examples, qualified accounting review, observed usability, installation and recovery checks, and clear support scope.

Does choosing a country or currency activate local accounting rules?

No. Each book uses one base currency. Country and currency choices do not activate tax calculations, statutory reporting, foreign-currency posting or additional accounting books. Regional accounting work follows the Pakistan, UK and UAE research and review sequence.

How can I help shape the next release?

Share a synthetic workflow example, installation report or reproducible issue through the project repository. Accountants, business owners and contributors can also use the Support page to prepare an email about review or pilot participation.
