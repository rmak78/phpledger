PHP Ledger

PHP Ledger is open-source, self-hosted double-entry accounting software with core invoices, bills and payments, optional purchasing and inventory, and a manually configured tax engine. Built on PHP 8.2+ and MySQL 8.4, it is a development preview for synthetic evaluation.

Current development preview: 0.4.0-preview (2026-09-16).
New project-owned code: AGPL-3.0-or-later; commercial licensing available. Pre-adoption 0.1.0 through 0.1.5 previews retain MIT; dependencies and archived code keep their own terms.

Read https://phpledger.com/llms.txt and https://phpledger.com/ai/summary.json.
Contact: rmak78@gmail.com. The public demo uses synthetic data and resets hourly.
The static website has no analytics; the separate application has a documented optional country lookup.
