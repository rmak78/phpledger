Install from the included guide

  1. Unpack privately

    Read INSTALL.md. Keep configuration, dependencies and installation tools outside the web document root.

  2. Configure the host

    Use a dedicated database account and private config. Set production mode, HTTPS and routing as described in the package.

  3. Check and initialize

    Run preflight, migration and preflight again, proceeding only when each command succeeds. Keep all eleven migration files supplied with this version, including both distinct 006 files and the module lifecycle migration. Never rename or change an applied migration.

  4. Verify with sample books

    Create the initial sign-in user using secure stdin. Test a sample receipt, account statement, general-journal draft, posting, report and linked reversal.

Frequently asked questions

What hosting does this package need?

Use PHP 8.5.x for both web and command-line requests, MySQL 8.4 with InnoDB, HTTPS, terminal access and private writable PHP session storage. PHP needs BCMath, PDO, PDO MySQL and mbstring. Serve only www/phpledger/public; MariaDB is not validated for this package.

Do I need Composer to install the download?

No. The ZIP includes production dependencies and its installation guide. Keep vendor files, configuration and installation tools outside the web document root.

How do I check that the ZIP is intact?

Download the ZIP and its SHA-256 file from the same GitHub release. Calculate the ZIP checksum using the command above and compare it with the published checksum before unpacking.

Does downloading the ZIP upgrade my existing installation?

No. Read the included UPGRADE.md, which covers recognized prior modern installations. Back up the database and application, rehearse restoration, then follow its maintenance, preflight and migration steps. Historical installations and customized schemas need separate review.

Can I bring an existing business into the preview?

The preview supports opening trial-balance/CSV review, explicit cutover confirmation and an unpaid-document register reconciled to control accounts. Detailed historical imports and AR/AP settlement are not included. Use synthetic data for evaluation and obtain accounting review before a business cutover.
