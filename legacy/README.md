# Historical PHP Ledger application

This directory preserves the earlier application from the repository root. It is archived for reference and is not loaded, supported or shipped by the modern application.

The current application lives in `www/phpledger`; only `www/phpledger/public` may be served. Follow the root README and `docs/DEVELOPMENT.md` for the current project. Never import these historical SQL dumps into the new database.

Git history is preserved. This relocation does not upgrade or relicense historical code or bundled libraries. See the root `LICENSE-SCOPE.md` and existing component notices. Legacy provenance remains under review.
